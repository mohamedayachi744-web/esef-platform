# دروسي

منصة طلابية تجمع روابط الدروس والامتحانات السابقة والمراجع لطلبة المدرسة العليا للتربية والتكوين بالقنيطرة.

- موقع ثابت (HTML وCSS وJavaScript) يُنشر على GitHub Pages.
- البيانات والحسابات على Supabase، والحماية بقواعد Row Level Security في قاعدة البيانات.
- لا توجد أسرار في هذا المستودع. المفتاح الظاهر في `data.js` مفتاح عام مخصص للمتصفح.

## التشغيل محلياً
افتح المجلد في VS Code وشغّل الإضافة Live Server على `index.html`.

## تعديل المقرر
المقرر في `data.js`. لا تغيّر قيمة `id` لأي فصل أو مادة بعد إضافة مصادر إليها، ولمادة جديدة اختر `id` لم يُستعمل من قبل.

## الإبلاغ عن مشكلة أمنية
راسلونا عبر البريد المنشور في صفحة «عن المنصة» في الموقع، ولا تنشروا التفاصيل علناً قبل إصلاحها.

## ملاحظة عن المكتبات
`supabase.js` نسخة محلية من مكتبة supabase-js الإصدار 2.58.0 (UMD). لا تحدّثها دون اختبار الدخول والنشر والمراجعة.
